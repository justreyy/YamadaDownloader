KUSTOMISASI CEPAT

1. Nama website:
   index.html -> YamadaDownloader

2. WhatsApp:
   app.js -> CONFIG.whatsappChannel

3. Customer Service:
   app.js -> CONFIG.customerService

4. Banner:
   ganti file banner.mp4 dengan banner kamu.

5. Logo:
   logo memakai LOGO.jpg (atau ubah URL logo dari Panel Admin).

6. Credits:
   edit bagian <section class="credits"> di index.html.

7. Warna:
   edit variable di paling atas style.css:
   --bg, --primary, --primary-dark, --surface, dll.

8. API:
   Vercel -> Settings -> Environment Variables (lihat .env.example).
